# 💻 Meu Projeto de Calculadora Web

## 👋 Introdução

Este projeto é uma **calculadora web simples**. O objetivo era aprender a juntar as três partes principais do desenvolvimento web:
* **HTML** (para a estrutura da calculadora)
* **CSS** (para deixar a calculadora bonita e organizada)
* **JavaScript** (para fazer os cálculos funcionarem)

## ✅ O Que a Calculadora Faz

A calculadora consegue fazer as 4 operações básicas, além de algumas funções extras que coloquei como desafio.

### Funções Principais
* Soma (`+`)
* Subtração (`-`)
* Multiplicação (`*`)
* Divisão (`/`)

### Desafios que Consegui Fazer (Funcionalidades Extras)
* **Porcentagem** (`%`) e **Raiz Quadrada** (`√`).
* **Números Decimais** (ex: `1.5 + 2.5`).
* **Uso do Teclado**: Dá para digitar os números e as operações usando o teclado do computador.
* **Histórico de Cálculos**: Tem uma **segunda página** (`historico.html`) dedicada onde todos os cálculos que fiz ficam salvos. Eu usei o **Local Storage** do navegador para guardar isso.

## ⚙️ Tecnologias Usadas

| Tecnologia | O que eu usei para fazer |
| :--- | :--- |
| **HTML** | A estrutura de botões e o display (`index.html` e `historico.html`). |
| **CSS** | As cores, o tamanho da calculadora e como ela se ajusta na tela (`style.css`). |
| **JavaScript** | Toda a lógica por trás: calcular os resultados, guardar o histórico e reconhecer as teclas (`script.js`). |

## 📂 Como Ver o Projeto

O projeto está dividido em quatro arquivos:
* `index.html` (A calculadora)
* `style.css` (Os estilos)
* `script.js` (A lógica)
* `historico.html` (O histórico)
